# LUWI

LUWI es una plataforma inteligente orientada a la formación personalizada de candidatos previo a su incorporación laboral.

## Tecnologías

### Frontend
- React
- Vite
- React Router
- Axios

### Backend
- Node.js
- Express
- Mongoose
- JWT

### Base de datos
- MongoDB Atlas

## Estructura

El proyecto está dividido principalmente en:

- `frontend/`: interfaz de usuario.
- `backend/`: API y lógica del sistema.
- `docs/`: documentación técnica.
- `.github/`: configuración relacionada con GitHub y CI/CD.

## Módulos iniciales

- Autenticación
- Empresas
- Candidatos
- Capacitación
- Inteligencia Artificial
- Seguimiento
- Dashboard

## Instalación

Clonar el repositorio:

git clone https://github.com/JuanLuis2121/LUWI.git

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
npm run dev

## Variables de entorno

Las variables necesarias se encuentran documentadas en `.env.example`.

Las credenciales reales no deben subirse al repositorio.

## Flujo de Git

El proyecto utiliza:

- `main`: versión estable.
- `develop`: integración del desarrollo.
- `feature/*`: desarrollo de funcionalidades.

Las funcionalidades deben integrarse mediante Pull Request.
